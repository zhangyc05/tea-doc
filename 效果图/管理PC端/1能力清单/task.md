# 能力清单模块页面实现任务包

## 一、任务背景

本任务不是自由设计页面，而是根据已识别的 7 张效果图实现「管理端 PC｜能力清单」模块页面。

页面内容、布局、字段、按钮、状态，必须来自效果图识别结果。

`AbilityListExecutionPage.vue` 只作为代码风格基准，不作为其他页面的内容来源。

执行原则：

```txt
效果图 = 页面内容与布局依据
AbilityListExecutionPage.vue = 管理端代码风格基准
main.css = 通用样式优先复用来源
产品业务口径 = 字段和流程合理性校验
```

不得凭空新增效果图中没有的业务模块、按钮、字段、状态。

能力清单有二级菜单：

```txt
能力清单
- 基准模板
- 执行版
```

最终交互应为：

```txt
1. 管理端默认显示完整侧栏。
2. 点击“能力清单”父级菜单，可以展开 / 收起二级菜单。
3. 点击“基准模板”进入基准模板页。

6. Rail 状态点击一级图标，跳转默认页并展开完整侧栏。
```

注意：有二级菜单的父级菜单本身不再承担直接跳转，跳转交给二级菜单。
