## 一、端口定位与设计原则

### 1.1 端口定位

系统管理端是平台运行保障工作空间，面向配置版本、数据任务、服务日志、权限组织和系统异常等运行对象。系统管理员通过它判断平台是否稳定、故障发生在哪里、受控操作产生什么影响，以及如何留下可追溯记录。

系统管理端不处理教师成长事务，也不替代业务主管或部门管理者进行材料审核、线索核查和档案办理。

### 1.2 设计原则

| 原则 | 设计要求 |
| --- | --- |
| 运行对象明确 | 首屏应直接出现环境、任务、配置版本、异常或审计记录等系统对象。 |
| 风险优先定位 | 失败、部分成功、未发布或高风险变更优先于正常运行信息。 |
| 操作受控可追溯 | 发布、停用、回滚、重试和权限变更均需说明影响并保留记录。 |
| 诊断链路完整 | 从摘要到列表、详情日志、关联异常与历史操作可以连续定位问题。 |
| 业务语义隔离 | 不出现教师个人成长建议、业务审核或“转为候选”等处理话术。 |
| 高密度但不大屏化 | 支持扫描任务和日志，但不以监控大屏或装饰性图表取代操作工作区。 |

### 1.3 能力边界

| 系统管理端允许能力 | 不属于系统管理端的能力 |
| --- | --- |
| 查看任务健康、失败原因、执行日志与重试记录 | 审核公开线索、确认教师材料入档 |
| 发布、停用、回滚系统配置或规则版本（按页面权限） | 展示教师个人成长建议、催促本人补充材料 |
| 管理权限、组织映射、服务通道和审计日志 | 业务质量分析中的部门绩效判断 |
| 执行受控重试、导出审计和关联异常定位 | 代替业务人员作出认定或审核结论 |

## 二、固定壳层与空间组织

### 2.1 壳层总结构

系统管理端采用稳定侧栏和环境上下文驱动的运维布局，以任务、配置和日志的快速定位为主。

```text
系统侧栏：运行概览 / 配置与版本 / 任务监控 / 权限组织 / 审计与异常
顶部环境栏：环境 / 服务或模块 / 当前版本 / 最近同步时间 / 管理员入口
页面标题与操作区：运行对象说明 / 风险提示 / 受控页面级动作
健康摘要区：失败、运行中、待处理异常、版本或告警摘要
主操作区：配置/任务/权限/日志列表或版本对比
诊断详情区：执行日志、失败原因、版本差异、变更影响或审计详情
确认与留痕层：重试、发布、停用、回滚或导出的确认弹窗与结果反馈
```

### 2.2 区域职责

| 区域 | 固定职责 | 设计约束 |
| --- | --- | --- |
| 系统侧栏 | 提供按运行职责组织的稳定入口 | 不放置教师办理或业务审核菜单 |
| 环境信息区 | 明确当前环境、模块、版本和时间上下文 | 环境/版本差异应在风险操作前持续可见 |
| 健康摘要 | 快速发现失败、异常、运行中或待发布对象 | 以可处理运行事实为主，不设计管理统计看板 |
| 主操作表格 | 浏览任务、配置项、权限或日志记录 | 强化状态、版本、执行时间、影响范围与操作入口 |
| 详情/日志区 | 定位失败、查看差异并判断后续操作 | 可采用右侧面板或抽屉，日志需有时间与步骤层级 |
| 确认反馈区 | 对高影响动作二次确认并说明结果 | 显示影响范围、可能风险、操作人和留痕去向 |

### 2.3 信息优先级

系统管理页面统一按照以下顺序组织：

1. 当前处于哪个环境、模块或服务上下文。
2. 是否有失败、异常、待发布或需要立即确认的运行对象。
3. 对象列表中哪条记录需要定位或操作。
4. 失败日志、版本差异、关联异常和操作影响。
5. 历史记录、导出或审计追踪。

### 2.4 表格与日志呈现

| 对象 | 列表关键字段 | 详情重点 |
| --- | --- | --- |
| 任务 | 任务名称、类型、状态、环境、最近运行、耗时、触发方式 | 执行步骤、失败原因、输入/输出摘要、重试记录、关联异常 |
| 配置版本 | 配置对象、版本、状态、发布时间、影响范围 | 差异、验证结果、发布/回滚记录 |
| 权限组织 | 对象、授权角色、范围、有效期、状态 | 变更前后、审批依据、影响对象 |
| 审计日志 | 操作类型、对象、操作人、时间、结果 | 变更内容、来源、请求/结果摘要和导出 |

## 三、页面模式

### 3.1 配置管理模式

| 项目 | 规范 |
| --- | --- |
| 适用页面 | 数据规则配置页、培训配置页、评聘配置页、模板管理页、通道配置页 |
| 首屏优先级 | 当前模块与生效版本 > 配置状态与风险 > 配置列表/差异 > 发布或回滚记录 |
| 允许操作 | 编辑草稿、验证、发布、停用、回滚、查看影响范围，按权限提供 |
| 推荐结构 | 环境与版本摘要 + 配置列表/Tabs + 版本差异详情 + 发布确认 |
| 不可出现 | 教师补充材料或管理业务审核动作 |

### 3.2 任务监控模式

| 项目 | 规范 |
| --- | --- |
| 适用页面 | 数据任务监控页、模型与任务管理页、模块任务日志页、失败监控页 |
| 首屏优先级 | 环境/同步上下文 > 失败与运行中摘要 > 任务列表 > 失败日志和受控重试 |
| 允许操作 | 筛选任务、查看日志、查看关联异常、确认重试、导出记录 |
| 推荐结构 | 健康摘要 + 任务筛选表格 + 详情日志面板/抽屉 + 重试确认弹窗 |
| 不可出现 | 线索审核、确认入档、教师行动提醒、业务统计大屏 |

### 3.3 异常处理模式

| 项目 | 规范 |
| --- | --- |
| 适用页面 | 系统失败监控、数据处理异常的系统管理员视图 |
| 首屏优先级 | 异常级别与影响范围 > 异常列表 > 关联任务/日志 > 处置与留痕 |
| 允许操作 | 标记定位结果、触发受控重试、关闭系统异常、导出诊断信息 |
| 推荐结构 | 风险摘要 + 异常队列 + 诊断详情 + 处置记录 |
| 不可出现 | 代替管理人员判断业务材料真伪或入档结果 |

### 3.4 权限组织模式

| 项目 | 规范 |
| --- | --- |
| 适用页面 | 权限配置页、组织与角色管理页 |
| 首屏优先级 | 授权范围与风险提示 > 角色/组织列表 > 授权详情 > 变更影响与确认 |
| 允许操作 | 新增授权、调整范围、停用授权、查看变更记录 |
| 推荐结构 | 权限筛选 + 对象列表 + 授权详情 + 变更确认/审计入口 |
| 不可出现 | 在权限配置页处理具体教师业务待办 |

### 3.5 审计日志模式

| 项目 | 规范 |
| --- | --- |
| 适用页面 | 操作日志与审计页及各配置/任务页的审计明细 |
| 首屏优先级 | 审计范围与时间 > 关键变更/失败记录 > 详情 > 导出 |
| 允许操作 | 条件检索、查看详情、导出审计记录 |
| 推荐结构 | 范围筛选 + 日志列表 + 事件详情/差异 + 导出说明 |
| 不可出现 | 直接更改业务事实或代为执行业务审核 |

## 四、组件语义与操作反馈

### 4.1 核心组件

| 组件 | 用途 | 表达规则 |
| --- | --- | --- |
| 环境/版本标识 | 明确操作所处上下文 | 在顶部持续显示，风险操作弹窗中再次确认 |
| 健康摘要卡 | 聚焦失败、运行中、告警和待发布对象 | 指标均应可定位到对象列表，不堆叠无操作意义的图表 |
| 任务/配置表格 | 快速扫描运行对象 | 状态、时间、版本、影响范围和操作列清晰可读 |
| 日志详情抽屉 | 查看步骤、失败原因和重试轨迹 | 默认聚焦异常步骤，保留完整时间序列入口 |
| 版本差异面板 | 比较变更并支撑发布/回滚 | 展示变更摘要、影响对象及验证状态 |
| 高风险确认弹窗 | 承载发布、停用、回滚或重试确认 | 必须说明操作对象、范围、风险、预计结果与留痕 |
| 审计时间线 | 追踪配置或运行处置 | 记录操作人、时间、动作、结果和相关版本/任务 |

### 4.2 运行状态表达

| 状态 | 页面表现 | 可用动作 |
| --- | --- | --- |
| `运行中` | 中性突出，展示开始时间或进度摘要 | 查看详情；通常不可重复触发重试 |
| `成功` | 弱化展示，保留结果与最近完成时间 | 查看日志或导出记录 |
| `部分成功` | 警示展示，显示失败分段与影响范围 | 查看失败项、定位异常、按权限重试 |
| `失败` | 首要警示状态，显示失败原因入口 | 查看日志、查看关联异常、确认重试 |
| `重试中` | 表明触发来源与新执行记录 | 查看新日志；避免重复重试 |
| `已停用/已回滚` | 显示生效版本与变更时间 | 查看历史或按权限恢复 |

### 4.3 受控操作反馈

| 操作 | 确认前必须说明 | 完成后必须反馈 |
| --- | --- | --- |
| 重试任务 | 失败原因、重试范围、可能影响、当前环境 | 新任务/执行状态、记录时间、日志查看入口 |
| 发布配置 | 版本差异、影响范围、验证状态 | 已生效版本、发布时间、审计记录入口 |
| 停用/回滚 | 当前生效状态、受影响服务或业务入口 | 回滚/停用结果、生效范围、恢复路径或审计记录 |
| 权限变更 | 授权对象、范围、有效期与影响对象 | 最新授权状态、变更人、留痕入口 |

## 五、首轮验证页面约束

### 5.1 `02-P-009` 数据任务监控页

| 项目 | 必须满足 |
| --- | --- |
| 页面模式 | 任务监控模式 |
| 授权角色 | 系统管理员 |
| 默认对象 | `TASK-SYNC-001`，默认状态为 `运行中` |
| 核心任务 | 查看数据归集或解析任务运行状况，定位失败原因，执行受控重试并查看日志留痕 |
| 首屏结构 | 环境/同步上下文、任务健康摘要、任务筛选与列表、失败任务重点呈现、日志详情和重试入口 |
| 核心状态 | 运行中、成功、失败、重试中；失败与部分成功应比正常任务醒目 |
| 主操作 | 查看详情/日志；在可重试状态执行 `确认重试` |
| 禁止项 | 教师个人档案内容、待核实线索审核、确认入档、管理分析话术、监控大屏堆图 |

### 5.2 日志与重试语义

- 任务详情应显示执行日志、失败原因、重试记录与关联异常入口。
- 重试必须通过确认弹窗触发，提示重试范围与可能影响。
- 重试发起后显示新的执行状态或日志记录，不能只以瞬时提示代替结果。
- 页面不得以任务运行结论代替业务数据核实或业务审核结果。

## 六、禁止项

| 类别 | 禁止内容 |
| --- | --- |
| 角色越界 | 教师补充材料、教师成长建议、公开线索业务审核、档案确认入档 |
| 操作失控 | 无影响说明的发布、回滚、停用或重试；无记录的权限变更 |
| 布局误向 | 做成业务审核双栏页或管理统计大屏；以成功任务堆积淹没失败定位 |
| 状态误义 | 将系统任务成功表述为业务已审核或教师档案已更新 |
| 追溯缺失 | 操作后不展示日志、版本、操作人或审计入口 |

## 七、验收清单

### 7.1 规范级验收

- [ ] 页面是否持续展示环境、版本或运行对象上下文。
- [ ] 壳层是否由系统侧栏、环境信息、健康摘要、主操作表格和详情诊断区构成。
- [ ] 配置管理、任务监控、异常处理、权限组织、审计日志五类模式是否边界清晰。
- [ ] 发布、停用、回滚、重试和权限变更是否具备影响说明与留痕要求。
- [ ] 是否明确排除教师成长办理和业务审核话术。

### 7.2 成长档案验证页验收

- [ ] `02-P-009` 是否显示任务健康摘要、任务列表、日志详情和重试入口。
- [ ] 失败与部分成功任务是否比成功任务更容易定位。
- [ ] 重试是否有确认、反馈与日志记录语义。
- [ ] 是否避免公开线索审核、教师档案内容和管理分析表达。
- [ ] 页面是否是一处可诊断、可追溯的系统运行工作区，而非图表展示大屏。

## 八、后续使用规则

1. 具体系统管理页面方案必须继承本文的壳层、模式、运行状态与受控操作规则。
2. 同时被业务角色访问的公共页面必须按路由权限和页面方案限定能力，不能默认继承系统管理操作。
3. HTML 原型仅在页面方案和新版 HTML 生成与验收规范确认后创建。

**方向确认记录（2026-05-25）**：使用者确认以本规范所定义的系统运行保障工作区方向作为后续系统管理端页面扩展基准。后续系统管理页面须保持环境、任务、诊断与受控操作语义，不得改造成教师办理或管理审核页面。
