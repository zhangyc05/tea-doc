## 一、推进价值与页面核心任务

`02-P-003` 是教师从 `02-P-001` 我的成长档案页和 `02-P-002` 待确认数据页进入的材料补充承接页，用于把“我需要补什么、为什么补、补完后到哪里确认”表达清楚。

本页核心任务固定为：

1. 教师围绕已登记材料对象查看补充要求、来源依据和提交说明。
2. 教师上传或模拟选择材料附件，填写必要说明。
3. 提交后仅形成“待部门确认”的页面内反馈，并回到 `02-P-002` 或保持在当前页展示提交结果。
4. 不在本页完成确认入档；入档确认仍由 `02-P-002` 的管理身份完成。

本页不是档案总览、审核页、异常处理页或系统任务页。

## 二、角色与壳层规则

| 当前角色 | 壳层表现 | 本页任务 | 允许动作 |
| --- | --- | --- | --- |
| 教师 `teacher` | 教师端顶部个人导航 | 补充本人材料 | 选择材料、填写说明、提交补充、返回待确认页 |
| 部门管理者 `department_manager` | `U` 页面可显示管理壳层或无办理说明 | 仅查看教师补充入口的目标页说明 | 不代替教师上传；可返回 `02-P-002` |
| 业务主管部门 `business_manager` | `U` 页面可显示管理壳层或无办理说明 | 仅查看授权范围内补证说明 | 不代替教师上传；不确认入档 |
| 其他角色 | 无权限 | 不展示材料详情 | 返回授权入口 |

首轮 HTML 建议优先实现教师完整提交流程；管理身份只需保证不会看到教师式上传表单或越权补充操作。

## 四、首屏结构

```text
教师端顶部个人导航
页面标题区：材料上传 / 当前对象 / 来源提醒
补充要求卡：为什么需要补充、截止时间、所属维度、目标字段
材料选择区：上传控件、材料类型、文件清单、格式提示
补充说明区：文字说明、来源单位、时间范围、备注
提交影响区：提交后进入部门确认，不直接入档
操作区：提交补充、保存草稿、返回待确认页
```

### 4.1 标题与提醒区

- 标题：`材料上传`
- 副标题：围绕当前材料对象补充依据，提交后进入部门确认。
- 状态标签：`待补充`、`草稿`、`已提交待确认`。
- 对象标识：必须展示 `DOC-2026-018` 或 `DOC-2026-024`。

### 4.2 补充要求卡

必须展示：

| 字段 | 示例 |
| --- | --- |
| 材料名称 | 2025 年企业岗位实践结项证明 |
| 所属维度 | D4 企业实践 |
| 来源提醒 | MSG-2026-104 历史档案材料确认待办 |
| 需要补充 | 实践单位、实践周期、岗位任务、结项证明 |
| 截止时间 | 2026-05-28 |
| 提交后去向 | 部门管理者确认后才进入正式档案 |

### 4.3 材料选择区

可采用模拟上传，不依赖真实后端。页面应展示：

- 支持格式说明：PDF、图片或压缩包；
- 单个文件大小说明；
- 已选择文件列表；
- 删除文件；
- 未选择文件时的空状态；
- 提交前校验：没有文件时不能提交成功。

### 4.4 补充说明区

字段建议：

| 字段 | 要求 |
| --- | --- |
| 来源单位 | 默认 `智造云科技有限公司`，可编辑 |
| 实践时间 | 可填写或使用示例范围 |
| 补充说明 | 说明材料与当前档案对象的关系 |
| 联系方式 | 可选，不做真实校验 |
