## 一、页面核心任务

本页帮助部门管理者在当前部门范围内识别需要处理的档案事项，并从教师维度进入待确认数据、待审核公开线索或异常治理流程。

本页不是档案详情填报页，也不是质量评价看板。首屏回答三个问题：

1. 当前展示的是哪个部门范围和哪种演示场景。
2. 哪些档案事项已经形成明确待办，可以立即处理。
3. 应进入哪个登记页面完成确认、线索审核或异常治理。

**首要主操作**：`处理待确认`，承接管理快照中的 `DOC-2026-018`，后续进入已登记的 `02-P-002` 待确认数据页。

### 2.2 演示对象与可用状态

| 页面用途 | 可使用的既有对象 | 页面状态表达 |
| --- | --- | --- |

| 待确认材料 | `DOC-2026-018`、`MSG-2026-104` | `J-05` 管理快照中为待确认，主操作进入确认流程 |

### 2.3 管理快照规则

`J-05` 独立验收时，本页加载已登记的管理快照；连续演示时读取实际流程状态，不把快照反写成教师主旅程初始状态。

| 场景 | 本页表现 |
| --- | --- |
| 管理快照基线 | `DOC-2026-018` 为待确认；林知夏行显示待确认 `1`、待审核公开线索 `2`、异常 `0` |
| `DOC-2026-018` 完成确认后 | 待确认数减少，教师行提示材料已处理；本页仅表达状态反馈，不在页面内伪造入档确认过程 |
| 线索审核完成后 | 线索数随 `02-P-006` 的已转候选或已驳回状态更新，候选仍需后续确认 |

本页不得以单个演示教师推断全部门总体数据。教师数量卡必须标记为`当前演示教师`或`当前列表教师`，不得冒充真实学院总人数。


### 3.2 与已验证审核页的复用及差异

| 项目 | `02-P-004` 部门档案管理页 | `02-P-006` 公开线索审核页 |
| --- | --- | --- |
| 共用外壳 | `tea-work` 海洋蓝顶栏、白色分组侧栏、浅灰内容工作区 | 同左 |
| 页面模式 | 业务管理模式 | 审核处理模式 |
| 首屏对象 | 教师档案事项集合 | 单条公开线索与证据 |
| 主工作区 | 事实摘要 + 教师档案轻表格 | 线索列表 + 详情处理双栏 |
| 主操作 | 处理待确认、查看待审核线索 | 转为候选、要求补充、驳回 |

不得为了复用样式将本页做成线索审核详情页，也不得为呈现管理感引入系统任务、服务日志或规则发布入口。

## 五、摘要、提示与轻表格设计

### 5.1 事实摘要

摘要卡只显示有数据依据的可解释事实，不展示完整率、覆盖率、质量评分或排名。

| 摘要项 | 管理快照示例 | 点击或含义 |
| --- | ---: | --- |
| 当前列表教师 | `1` | 当前样板只展示已登记的林知夏，不代表部门总人数 |
| 待补充材料 | `0` | 管理快照中材料已进入待确认，不再作为教师待补充事项展示 |
| 待确认数据 | `1` | 对应 `DOC-2026-018`，进入待确认处理说明 |
| 待审核公开线索 | `2` | 对应两条 `ARCH-CLUE-*`，进入 `02-P-006` |
| 异常 | `0` | 未登记具体异常对象，显示空状态 |

### 5.2 条件提示

首屏优先展示一条可执行提示：

| 提示内容 | 依据 | 操作 |
| --- | --- | --- |
| `林知夏 · 2025 年企业岗位实践结项证明待确认` | `DOC-2026-018` / `MSG-2026-104` | `处理待确认`，后续目标为 `02-P-002` |

因 `02-P-002` 尚未在当前已生成批次内创建，HTML 样板在获准生成该目标页前只能保留目标 ID 和待建说明，不创建坏链接或空白占位页。

### 5.3 教师档案轻表格

| 列 | 示例表现 | 交互要求 |
| --- | --- | --- |
| 教师 | 林知夏 / 智能制造学院 | 可查看档案事项摘要，不展开个人办理壳层 |
| 待补充材料 | `0` | 无需操作时显示短横线或 `0` |
| 待确认 | `1` | `处理待确认`，承接 `DOC-2026-018` |
| 待审核公开线索 | `2` | `查看线索`，进入已经生成的 `02-P-006` |
| 异常 | `0` | 无对象时不得出现可操作异常详情 |
| 最近更新 | 按管理快照演示时间展示 | 用于扫描先后，不编造历史动作 |
| 操作 | 处理待确认 / 查看线索 | 只呈现当前具有依据的操作 |

## 六、关键交互与路由承接

| 触发动作 | 展现方式 | 路由或状态结果 |
| --- | --- | --- |
| 点击`处理待确认` | 提示待确认数据页目标与对象 | 目标 `02-P-002`，透传 `role=department_manager`、`object=DOC-2026-018`、`journey=J-05`；目标页创建前使用待建说明 |
| 点击`查看线索` | 导航至公开线索审核页 | 进入已生成 `02-P-006`，透传 `role=department_manager`、`journey=J-05` |
| 点击异常摘要 | 异常为 `0` 时显示空状态说明 | 不进入尚无对象支撑的处理流程 |
| 筛选仅看待处理 | 表格保留有待确认或待审核线索的教师行 | 不改变共享对象状态 |
| 后续确认处理完成 | 返回或重新进入本页时刷新摘要与教师行 | 按共享状态显示处理结果，不自行生成新记录 |

## 七、状态与权限边界

### 7.1 页面状态

| 状态 | 页面表现 |
| --- | --- |
| `snapshot` 管理快照 | 默认验收状态，明确显示当前为 `J-05` 演示快照 |
| `processed` 待确认已处理 | 待确认摘要为 `0`，提示最近事项已完成确认；正式入档结论由后续目标页状态负责 |
| `no-task` 无当前待办 | 事实摘要保留，轻表格显示无待处理事项提示 |
| 无权限访问 | 不渲染教师或待办数据，仅说明部门管理者授权要求 |

### 7.2 明确禁止项

- 不显示系统任务重试、服务日志、规则发布、权限配置等系统管理能力。
- 不展示教师个人上传材料的办理式主内容，不代替 `02-P-002` 执行确认入档。
- 不展示`档案完整度`、综合质量分、覆盖率或没有明确定义的比例。
- 不将待审核公开线索显示为正式档案记录。
- 不创建未在共享数据基线登记、且需要跨页回写的异常教师或异常材料。
