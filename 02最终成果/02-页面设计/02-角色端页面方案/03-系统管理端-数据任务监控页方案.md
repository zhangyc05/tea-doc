## 一、页面核心任务

本页让系统管理员孙嘉禾查看数据归集、解析或线索发现等平台任务的运行状况，快速找到失败或部分成功的执行记录，检查日志与关联异常，并在明确影响范围后执行受控重试。

页面关注的是平台运行保障，而不是成长档案内容审核。任务运行成功不代表任何教师材料、公开线索或正式档案已经完成业务确认。

**首要操作**：查看任务详情与日志；仅在失败或具备重试条件的任务上提供`确认重试`。

## 二、页面上下文与演示状态

### 2.1 当前身份与默认对象

| 类型 | 对象 | 页面表达 |
| --- | --- | --- |
| 当前管理员 | `U-A-001` 孙嘉禾，信息化中心 / 平台管理员 | 系统管理端顶部管理员入口 |
| 默认任务 | `TASK-SYNC-001` 数据同步与业务任务日志 | 页面默认关注任务，初始状态为`运行中` |
| 关联审计上下文 | `AUDIT-2026-0523` 演示环境操作审计批次 | 操作留痕的目标语义，不擅自生成审计结果 |
| 关联配置上下文 | `DICT-ARCH-001` 或 `FLOW-ARCHIVE-001` | 仅在说明任务来源/关联对象时引用，不在本页发布规则 |

### 2.2 展示状态范围

业务契约要求本页能够检验`运行中`、`成功`、`失败`和`重试中`状态。共享基线明确登记的持久默认对象仅为状态`运行中`的 `TASK-SYNC-001`；其余状态用于页面条件样式、筛选和交互反馈演示，不作为跨页新业务对象写入。

| 状态 | 首屏用途 | 允许操作 |
| --- | --- | --- |
| `运行中` | 默认任务状态，显示当前执行上下文 | 查看日志，不重复触发重试 |
| `成功` | 弱化显示近期已完成记录的样式 | 查看日志或导出记录 |
| `失败` | 检验失败定位与重试入口的条件状态 | 查看失败原因、关联异常、确认重试 |
| `重试中` | 检验触发重试后的反馈状态 | 查看新日志，不重复重试 |

## 三、继承壳层与首屏布局

### 3.1 系统管理端壳层应用

```text
系统侧栏：运行概览 / 配置与版本 / 任务监控（当前） / 权限组织 / 审计与异常
顶部环境栏：演示环境 / 成长档案数据服务 / 当前运行上下文 / 最近同步时间 / 孙嘉禾
标题操作区：数据任务监控 + 运行说明 + 导出记录等低风险入口
健康摘要区：失败、运行中、部分成功/告警、近期重试等运行事实
主工作区：任务筛选与任务表格
诊断区：选中任务日志、失败原因、关联异常和重试记录
确认层：任务重试确认与操作反馈
```

本页不得采用管理端的线索审核双栏语义，也不得放置教师个人档案事实或成长行动卡片。

### 3.2 首屏信息结构

| 顺序 | 区块 | 必须内容 | 首屏目的 |
| ---: | --- | --- | --- |
| 1 | 环境信息区 | 当前环境、数据服务/模块、管理员、最近同步上下文 | 避免在错误环境执行操作 |
| 2 | 页面标题区 | `数据任务监控`、说明文字与受控操作入口 | 明确页面任务是运行保障 |
| 3 | 健康摘要区 | 失败、运行中、部分成功/告警、近期重试等运行摘要 | 优先定位风险 |
| 4 | 筛选工具条 | 任务类型、运行状态、模块、触发时间、关键词 | 聚焦任务记录 |
| 5 | 任务列表 | 名称、类型、状态、最近运行、耗时、触发方式、操作 | 定位执行对象 |
| 6 | 日志/诊断详情 | 执行步骤、状态、失败原因或运行轨迹、关联异常、重试记录 | 支持诊断和追溯 |
| 7 | 重试确认与反馈 | 失败时出现的受控重试操作 | 避免无影响说明的重新执行 |

## 四、健康摘要与任务列表

### 4.1 健康摘要

摘要只呈现可定位到运行对象的事实，不设计业务管理指标或展示型监控大屏。

| 摘要项 | 展示目的 | 交互结果 |
| --- | --- | --- |
| 失败任务 | 优先找出需要诊断或重试的执行 | 筛选失败任务 |
| 运行中任务 | 查看当前正在执行的任务 | 筛选运行中任务并查看日志 |
| 部分成功/告警 | 定位存在局部异常的执行 | 打开影响范围与异常信息 |
| 近期重试 | 查看近期人工触发的受控操作 | 查看重试记录和日志 |

### 4.2 筛选工具条

| 筛选项 | 设计要求 |
| --- | --- |
| 任务类型 | 支持数据同步、AI 解析、线索发现、共享等契约规定的任务类型表达 |
| 运行状态 | 默认包含`运行中`、`失败`等重点状态选择 |
| 所属模块/服务 | 默认突出成长档案相关上下文 |
| 触发时间 | 支持筛选执行时间范围 |
| 关键词 | 搜索任务名称或任务标识 |

### 4.3 任务表格

| 字段 | 默认任务示例/表达要求 |
| --- | --- |
| 任务标识 | `TASK-SYNC-001` |
| 任务名称 | `数据同步与业务任务日志` |
| 任务类型 | 与数据同步上下文对应的类型 |
| 状态 | `运行中`；失败样式用于可重试条件状态演示 |
| 所属模块/环境 | 成长档案 / 当前演示环境 |
| 最近运行时间 | 读取或展示演示上下文中的时间信息，不推导业务结论 |
| 触发方式 | 定时或人工触发等运行语义 |
| 操作 | `查看详情`；仅失败可展示`重试`入口 |

成功任务应视觉弱化，失败和部分成功状态在列表中更易定位。

## 五、诊断详情与受控重试

### 5.1 任务详情/日志区

选中任务后，详情面板或抽屉必须支持下列信息层级：

| 信息组 | 内容要求 |
| --- | --- |
| 任务概览 | 任务名称、任务 ID、任务类型、状态、环境、触发方式与执行时间 |
| 执行轨迹 | 各步骤时间、步骤状态和当前运行进展 |
| 失败定位 | 仅在失败/部分成功条件出现，展示失败步骤、原因说明与影响范围 |
| 关联异常 | 提供查看关联异常的入口，避免在列表中塞入完整诊断内容 |
| 重试记录 | 展示是否重试、触发人、时间与新执行状态 |
| 留痕说明 | 表示操作进入审计记录，不自行渲染未登记的业务处理结果 |

### 5.2 重试确认弹窗

重试入口仅在任务允许重试的失败条件状态出现。确认弹窗必须包含：

- 操作对象：任务名称与任务标识。
- 当前环境和所属模块。
- 失败原因摘要。
- 本次重试范围及可能影响。
- 提示该操作将记录于运行/审计留痕中。
- `确认重试`与`取消`操作。

### 5.3 重试后的反馈

| 动作后状态 | 页面反馈 |
| --- | --- |
| 已提交重试 | 原失败记录保留，展示新的`重试中`反馈或执行记录入口 |
| 重试执行中 | 显示新执行轨迹，禁用重复重试操作 |
| 重试结果可查看 | 提供日志与审计追溯入口 |

任务重试反馈不得表述为公开线索已核实、材料已入档或教师档案已更新。

## 六、关键交互与路由边界

| 触发动作 | 展现方式 | 结果与边界 |
| --- | --- | --- |
| 筛选任务 | 页面内筛选 | 改变当前任务列表，不修改业务对象状态 |
| 点击`查看详情` | 详情面板或任务日志抽屉 | 展示运行轨迹、失败原因、重试记录和关联异常 |
| 点击`查看关联异常` | 局部详情入口或按已登记页面方案后续跳转 | 只进入诊断上下文，不进行业务审核 |
| 点击`重试` | 重试确认弹窗 | 说明影响后才允许提交 |
| 确认重试 | 状态反馈区更新 | 产生重试中语义和日志留痕入口，不制造档案状态变化 |
| 访问无权限 | 无权限状态页面 | 不渲染任务内容，返回可访问入口 |

## 七、禁止表达与验收清单

### 7.1 页面不得出现

- 教师姓名作为待办主体的个人成长卡片、补充材料操作或画像建议。
- `待核实线索`的审核按钮、`转为候选`、`确认入档`等业务处理动作。
- 将任务运行结果描述为业务审核通过或档案已经更新。
- 管理质量看板式指标、部门筛选与审核记录话术。
- 无确认、无影响说明或无日志留痕的任务重试操作。

### 7.2 页面验收

- [ ] 页面继承系统管理端壳层，首屏可见环境、运行对象和风险摘要。
- [ ] 默认对象使用 `TASK-SYNC-001` 且基线状态为`运行中`。
- [ ] 条件状态能够表达失败定位、日志查看与受控重试，不新增跨页业务对象。
- [ ] 列表、详情、日志和重试反馈形成可诊断、可追溯的运行链路。
- [ ] 页面不包含教师办理、管理审核、公开线索处理或档案状态结论。
- [ ] 页面未被设计为装饰性监控大屏。
