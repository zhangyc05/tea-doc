## 一、推进价值与页面核心任务

`02-P-008` 用于补齐成长档案链路中的规则配置模式，明确“哪些公开来源、字段映射、入档条件和异常判定规则可以配置”，并把业务规则发布与系统运行保障区分开。

本页核心任务：

1. 业务主管部门查看或维护授权业务范围内的数据采集和入档规则草案。
2. 系统管理员查看规则版本、启停状态和发布留痕，保证规则可追溯。
3. 页面展示规则版本、适用范围、字段映射、异常触发条件和最近运行影响。
4. 规则配置不直接改变教师档案事实，不代替材料确认、线索审核或异常处理。

## 二、角色与壳层规则

| 当前角色 | 壳层 | 首屏任务 | 允许动作 |
| --- | --- | --- | --- |
| 业务主管部门 `business_manager` | 管理端 `M` | 查看并维护授权范围内业务规则草案 | 编辑草案、提交发布申请、查看影响说明 |
| 系统管理员 `admin` | 系统管理端 `A` | 管理规则版本和运行状态 | 发布、停用、回滚、查看审计 |
| 部门管理者、教师、校级领导 | 无权限或只读说明 | 不配置规则 | 不展示配置按钮 |

## 四、首屏结构

```text
动态壳层：业务主管部门 M / 系统管理员 A
标题区：数据规则配置 + 当前角色范围 + J-06
规则摘要区：规则数量、草案数量、生效规则、最近影响对象
规则列表区：规则 ID、名称、适用对象、状态、版本、最近更新
规则详情区：字段映射、触发条件、影响说明、审计记录
操作区：业务主管提交发布申请；系统管理员发布 / 停用 / 回滚
边界说明：规则变更不直接入档，只影响后续识别和候选生成
```

## 五、关键交互

| 触发 | 页面行为 | 后续状态 |
| --- | --- | --- |
| 选择规则 | 右侧详情切换字段映射和触发条件 | 不改变业务状态 |
| 业务主管编辑草案 | 页面内显示草案已修改 | 不直接发布生效 |
| 业务主管提交发布申请 | 显示待系统管理员发布 | `state=submitted` |
| 系统管理员发布规则 | 显示发布留痕 | `state=published` |
| 系统管理员停用规则 | 弹窗确认并显示停用说明 | `state=disabled` |
| 查看审计 | 弹层展示规则版本和操作记录 | 不创建新页面 |
