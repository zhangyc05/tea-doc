## 一、页面核心任务

本页让业务主管部门或校级领导在授权汇总范围内查看档案建设中的事实分布，识别仍需跟进的待确认材料和待审核线索，并通过明确下钻查看依据。

本页不是部门待办办理页，也不是无口径的综合评分大屏。由于现有共享数据仅登记一组成长档案演示对象，当前样板只能展示“已登记演示样本”的事实汇总，不得声称代表全校总体质量、学院排名或趋势结论。

**首要主操作**：`查看依据明细`，打开当前汇总口径与构成说明；业务主管部门可进一步进入已获准的公开线索审核页，校级领导保持只读查看。

## 二、角色、统计范围与数据边界

### 2.1 角色差异

| 当前角色 | 演示身份 | 范围表达 | 允许动作 |
| --- | --- | --- | --- |
| 业务主管部门 | `U-B-001` 陈璐，教师发展中心 / 主管 | 授权汇总视角；当前样板显示已登记演示样本 | 筛选、查看依据明细、查看待审核公开线索；不在看板内直接入档 |
| 校级领导 | `U-L-001` 王宁远，分管教学副校长 | 汇总只读视角；当前样板显示已登记演示样本 | 切换查看维度、查看说明和明细；不出现审核或处理按钮 |

部门管理者不是本页授权角色。部门业务办理已由确认样板 `02-P-004` 承载，不通过本看板扩大权限。

### 2.2 统计口径与可用对象

| 页面用途 | 可使用对象 | 本页表达 |
| --- | --- | --- |
| 正式档案构成 | `ARCH-REC-LIN-001` 至 `ARCH-REC-LIN-005` | `已入档记录 5`，按维度构成展示 |
| 待确认事项 | `DOC-2026-018` | `待确认材料 1`，只作为待跟进事实，不在本页办理确认 |
| 待审核线索 | `ARCH-CLUE-2026-001`、`ARCH-CLUE-2026-002` | `待审核公开线索 2`；主管可查看审核页，领导只读 |
| 异常事项 | 当前无已登记具体异常对象 | `已登记异常 0`，显示空状态说明 |
| 统计刷新与场景 | `journey=J-05` 管理快照；演示基点 `2026-05-23 09:30` | 标识为演示汇总快照，不冒充实时全校统计 |

### 2.3 不可直接使用的统计

目前未登记学院总体教师数、全校档案总量、质量分母、跨学院比较序列或时间趋势样本。因此本页不得生成：

- 档案完整率、覆盖率、质量得分、健康度、学院排名。
- 全校教师数量、异常比例、同比或环比趋势。
- 除智能制造学院已登记样本外的学院对比行或预警结论。

如后续需要上述表达，应先在共享数据基线中登记统计对象、口径、时间点与下钻关系，再修订页面方案。

图表标题须写明`已登记演示样本状态构成`，并在附近标记`不代表全校总体质量评价`。异常为 `0` 不强行进入图形占比，仅在指标和说明区展示。

| 下钻项 | 数量 | 依据摘要 | 可见动作 |
| --- | ---: | --- | --- |
| 正式档案记录 | `5` | 教学工作、教研科研、企业实践、成果荣誉、个人发展各一条 | 查看构成说明 |

## 六、关键交互与角色状态

| 触发动作 | 业务主管部门结果 | 校级领导结果 |
| --- | --- | --- |
| 切换状态或维度筛选 | 仅筛选已登记样本并同步主图与明细 | 同左，只读查看 |
| 点击`查看依据明细` | 展示指标口径、对象 ID 与刷新时间抽屉 | 同左，并显示只读提示 |
| 点击`查看线索` | 进入已生成 `02-P-006`，透传 `role=business_manager`、`object=ARCH-CLUE-2026-001`、`journey=J-05` | 不显示办理入口，改为线索依据说明 |
| 点击待确认材料 | 显示 `DOC-2026-018` 状态与待建目标说明，不在看板内处理 | 同左，只读说明 |
| 点击异常 `0` | 显示未登记具体异常对象的空状态 | 同左 |

### 6.1 页面状态

| 状态 | 页面表现 |
| --- | --- |
| `summary` 汇总快照 | 默认状态，完整展示四项事实指标、主图与下钻表 |
| `clue-focus` 聚焦待审核线索 | 主图强调两条待审核线索，明细定位到来源依据 |
| `empty-filter` 筛选无结果 | 指标和图表提示当前筛选下无登记样本，不新增空白部门数据 |
| `leader-readonly` 领导只读 | 显示王宁远身份与只读标识，隐藏处理性质的入口 |
| 无权限访问 | 对部门管理者、教师或系统管理员不渲染汇总数据，只展示授权说明 |

## 七、明确禁止项

- 不显示档案完整率、覆盖率、综合质量评分、排名、同比/环比或无数据支撑的预警。
- 不将单个演示教师或智能制造学院样本描述为全校统计结果。
- 不允许校级领导进入单条审核、确认入档、批量处理或规则配置。
- 不在本页提供系统任务重试、日志、规则发布、权限配置等系统管理动作。
- 不将待审核公开线索计入正式档案记录。
