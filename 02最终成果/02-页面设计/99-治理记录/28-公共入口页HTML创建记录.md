## 二、页面能力

| 能力 | 当前实现 |
| --- | --- |
| 身份选择 | 教师、部门管理者、业务主管部门、校级领导、系统管理员 |
| 推荐入口 | 按身份显示可进入的样板页面 |

| 系统治理链路 | 可快速进入系统任务监控链路 |
| 业务边界 | 本页不办理业务、不确认入档、不提交材料、不关闭异常 |
