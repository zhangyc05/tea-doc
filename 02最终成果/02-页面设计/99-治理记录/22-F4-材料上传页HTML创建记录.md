## 二、页面能力

| 能力 | 当前实现 |
| --- | --- |
| 教师端壳层 | 使用教师端顶部个人导航 |
| 默认对象 | `DOC-2026-018` 2025 年企业岗位实践结项证明 |
| 条件对象 | 支持 `DOC-2026-024` 作为实践结项报告变体 |
| 文件选择 | 使用模拟选择文件方式展示文件清单，不上传真实文件 |
| 提交校验 | 未选择文件时不能提交成功 |
| 提交反馈 | 提交后显示“已提交待确认”，不显示“已入档” |
| 返回承接 | 可返回 `02-P-002-待确认数据页.html` 并透传 `role=teacher`、`object`、`journey`、`state` |
| 越权访问 | 非教师身份显示无权限状态，不允许代替教师上传 |

## 四、建议验收 URL

```text
02-P-003-材料上传页.html?role=teacher&object=DOC-2026-018&journey=J-01&state=missing
02-P-003-材料上传页.html?role=teacher&object=DOC-2026-018&journey=J-01&state=submitted
02-P-003-材料上传页.html?role=department_manager&object=DOC-2026-018&journey=J-05
```

验收重点：

1. 教师视图是否为个人行动空间；
2. 未选择文件时是否拦截提交；
3. 选择模拟文件后是否能提交并进入“待确认”状态；
4. 返回 `02-P-002` 时参数是否保持；
5. 非教师身份是否无权限；
6. 窄屏下上传区、说明区和操作区是否可用。
