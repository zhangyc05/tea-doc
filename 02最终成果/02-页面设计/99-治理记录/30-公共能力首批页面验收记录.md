## 三、公共参数覆盖

| 参数 | 当前使用情况 |
| --- | --- |
| `role` | 全站入口、消息中心、无权限页均支持 |
| `object` | 消息中心和业务页面跳转时透传 |
| `journey` | 全站入口和消息中心跳转时透传 |
| `state` | 按目标页面需要透传，如 `missing`、`pending`、`submitted`、`candidate-risk` |
| `from` | 入口或消息中心跳转业务页面时透传来源 |
| `target` / `required` / `reason` | 无权限说明页用于展示拦截信息 |
