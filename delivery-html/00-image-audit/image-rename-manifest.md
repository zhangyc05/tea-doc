# 图片中文重命名清单

> 分支：`delivery-html-business-prototype-chinese-filenames-activity`  
> 目的：记录原始图片路径、校验后的真实页面名、中文新路径和实际执行状态。  
> 规则：图片文件名使用中文，HTML 文件名后续仍建议使用英文 / 拼音，方便开发部署。

## 命名规则

```text
端类型｜模块｜页面名称｜页面状态.png
```

说明：

- 使用中文语义，方便人工查看和对照页面；
- 使用全角竖线 `｜` 分隔，不使用 `/ \ : * ? " < > |` 等不安全字符；
- 多版本页面在校验完成前不立即重命名；
- 被确认跨模块归属的图片，可以在重命名时移动到正确模块目录。
