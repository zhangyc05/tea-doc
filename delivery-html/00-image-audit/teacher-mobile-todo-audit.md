## 4. 发现的业务校验点

1. **待办和系统消息必须分开**  
   待办承接待确认、待补充、可完善事项；铃铛进入系统消息，不进入全部待办。

2. **待办文案必须是具体动作**  
   例如“确认一条培训证书”“完善一篇教学反思”，不使用“补齐聘期要求证明缺口”这类宽泛表达。

3. **教师端不使用“候选数据”**  
   待确认培训证书应表达为“系统已帮您识别，请确认是否属于本人”。

4. **确认入档和修改提交是两条不同状态线**  
   - 确认入档：待确认 → 正式入档；
   - 修改提交：待确认 → 待核验，不应直接正式入档。

5. **“不是我的”需要确认具体页面状态**  
   当前文件名无法判断是二次确认页还是处理完成页，后续必须结合图片视觉内容复核。

6. **搜索无结果页可能应归入档案模块**  
   该图虽然放在待办目录，但按页面对象更像档案搜索空状态。
