# 05｜管理端页面任务

> 本文件用于指导管理端 PC 页面还原。管理端页面必须保持浅色教育 SaaS 风格，不得变成黑色重后台。

## 1. 管理端页面还原原则

```txt
1. 业务结构优先于视觉装饰
2. 页面信息层级必须清楚
3. 统计卡只统计当前页面业务对象
4. 不新增无依据字段、按钮、卡片
5. 左侧导航必须浅色
6. AI 入口固定为辅助入口，不自动产生正式结果
7. 列表、状态、抽屉优先复用通用组件
```

## 2. 管理端标准布局

管理端页面必须使用：

```txt
AdminLayout
```

标准结构：

```txt
左侧浅色导航
顶部栏
面包屑
页面标题区
筛选区
主内容区
右侧详情抽屉
右下角 AI 助理入口
```

## 3. 第一批管理端标准页面

```txt
T5.1 管理端｜培训管理｜资源库
T5.2 管理端｜培训管理｜需求管理
T5.3 管理端｜培训管理｜申请处理
T5.4 管理端｜分析报告｜卡片页
```

目标：验证管理端标准布局、卡片、筛选、列表、抽屉、AI 助理。

## 4. T5.1 管理端｜培训管理｜资源库

首个样板页选择资源库，因为它包含管理端典型结构：左侧菜单、顶部栏、面包屑、统计卡片、筛选区、列表、状态标签、操作按钮、右侧抽屉和 AI 助理入口。

### T5.1.1 创建资源库页面路由

修改文件：

```txt
frontend/src/router/admin.routes.ts
```

验收：

```txt
/admin/training/resources 可访问
菜单选中 培训管理 / 资源库
```

### T5.1.2 创建页面文件

新增文件：

```txt
frontend/src/pages/admin/training/ResourceLibraryPage.vue
```

页面结构必须包含：

```txt
PageHeader
StatCard 区域
FilterBar 区域
资源列表区域
DetailSheet
```

### T5.1.3 创建培训资源 mock 数据

新增或修改：

```txt
frontend/src/mock/admin/training.ts
```

必须导出：

```ts
export const trainingResourceStats = []
export const trainingResources = []
```

资源类型固定：

```txt
校内建设
外部机构
企业合作
公开课程
```

### T5.1.4 创建资源详情业务组件

新增：

```txt
frontend/src/components/business/training/TrainingResourceDetailSheet.vue
```

组件规则：

```txt
1. 使用 DetailSheet
2. 不直接写死 mock 数据
3. 从 props 接收 resource
4. 支持关闭
```

### T5.1.5 页面接入组件

ResourceLibraryPage 必须使用：

```txt
PageHeader
StatCard
FilterBar
StatusBadge
TrainingResourceDetailSheet
```

禁止：

```txt
1. 页面内直接写 Badge 展示状态
2. 页面内散落 mock 数组
3. 页面内重复写抽屉结构
```

### T5.1.6 资源库统计口径

统计卡只围绕资源本身：

```txt
资源总数
可用资源
信息待完善
资源类型数量
```

禁止统计：

```txt
涉及计划
匹配需求
覆盖教师
推荐命中
```

### T5.1.7 资源筛选项

建议筛选项：

```txt
关键词搜索
资源类型
可用状态
来源
```

禁止添加无依据筛选项。

### T5.1.8 资源列表字段

建议字段：

```txt
资源名称
资源类型
建设 / 提供方
适用方向
可用状态
信息完整度
更新时间
操作
```

### T5.1.9 资源详情抽屉字段

```txt
资源名称
资源类型
提供方
适用方向
资源说明
可用状态
信息完整度
更新时间
```

### T5.1.10 资源库页面最终验收

- [ ] 使用 AdminLayout

- [ ] 统计卡只围绕资源本身
- [ ] 资源类型为四类：校内建设、外部机构、企业合作、公开课程

## 5. 第一批后续页面拆分原则

完成 T5.1 后，T5.2、T5.3、T5.4 必须按同样粒度拆分，不得直接写一个大任务。

每个页面至少拆为：

```txt
1. 创建路由
2. 创建页面文件
3. 创建 mock 数据
4. 创建必要业务组件
5. 接入通用组件
6. 完成视觉与业务验收
```
