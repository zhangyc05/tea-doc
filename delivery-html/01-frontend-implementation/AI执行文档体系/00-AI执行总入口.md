# 00｜AI 执行总入口

> 适用对象：后续执行教师综合发展平台 Vue 前端落地任务的 AI。  
> 使用方式：每次执行任务前先读本文件，再按任务类型读取对应子文档。

## 1. 当前目标

把已确认的效果图、页面规划、业务规则和视觉风格，转化为可开发、可运行、可维护的 Vue 前端工程。

AI 不是重新设计产品，而是严格按任务编号落地前端。

## 2. 固定技术路线

```txt
Vue 3
Vite
TypeScript
Vue Router
Pinia
Tailwind CSS
shadcn-vue
ECharts
```

当前阶段不采用 Nuxt 3。禁止自行引入 Element Plus、Ant Design Vue、Naive UI 等大型组件库。

## 3. 每次任务执行协议

每次只执行一个明确任务编号。

```txt
读取本入口
→ 读取任务相关子文档
→ 确认任务编号
→ 判断输入资料是否足够
→ 只修改任务相关文件
→ 完成自检
→ 更新任务记录
→ 输出执行结果
```

普通任务建议最多修改 3 - 8 个文件。工程初始化任务可以超过，但必须说明原因。

## 5. 禁止事项

```txt
1. 禁止自行切换技术栈
2. 禁止自行改用 Nuxt 3
3. 禁止自行引入其他大型 UI 组件库
4. 禁止删除已有产品文档、效果图、校验文档
5. 禁止移动未确认的效果图文件
6. 禁止把管理端左侧菜单改成黑色、深蓝、深灰重后台风格
7. 禁止在教师端直接出现“候选数据”
8. 禁止新增没有业务依据的字段、卡片、按钮、统计项
9. 禁止把 AI 建议表达成正式结论
10. 禁止让 AI 自动发布、自动审核、自动确认入档
11. 禁止把 mock 数据散落在页面组件内部
12. 禁止为了通过类型检查大面积使用 any
13. 禁止在 build 失败时宣称任务完成
```

## 6. 不确定时处理规则

```txt
1. 优先查找已有文档、效果图、页面规划
2. 优先遵守已确认的用户规则
3. 优先采用更克制、更少字段、更低认知负担的方案
4. 不新增未经确认的业务结论
5. 在结果中标记待确认，不擅自脑补
```
