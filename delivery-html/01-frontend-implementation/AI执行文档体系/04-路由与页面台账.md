# 04｜路由与页面台账

> 本文件用于约束路由命名、页面映射、页面状态和页面开发台账，确保后续 AI 能按页面路径和任务编号连续执行。

## 1. 路由文件

路由拆分为：

```txt
frontend/src/router/index.ts
frontend/src/router/admin.routes.ts
frontend/src/router/teacher.routes.ts
frontend/src/router/mobile.routes.ts
```

## 2. 路由前缀

管理端统一使用：

```txt
/admin
```

教师手机端统一使用：

```txt
/mobile
```

教师 PC 端可根据后续工程规划使用：

```txt
/teacher
```

## 3. 路由 meta 规则

每个路由建议包含：

```ts
meta: {
  title: string
  module: string
  layout: 'admin' | 'teacher-pc' | 'mobile'
  menuKey?: string
  breadcrumb?: string[]
}
```

## 6. 页面台账文件

必须新增：

```txt

```

该文件是后续 AI 的页面执行台账。每完成一个页面，AI 必须更新该台账。


如果缺少对应效果图，应标记：

```txt
对应效果图缺失，本任务仅建立结构，不做最终视觉还原。
```

## 11. 页面完成标准

页面完成不是指“能显示”。

页面完成必须满足：

```txt
1. 路由可访问
2. 使用正确 Layout
3. 菜单选中状态正确
4. 面包屑正确
5. 页面主标题正确
6. 页面结构与效果图一致
7. 使用统一组件
8. mock 数据集中管理
9. 状态标签使用 StatusBadge
10. 无新增未确认字段
11. 无无意义按钮
12. 无风格跑偏
13. TypeScript 无明显错误
14. npm run build 通过
```

## 12. Mock 数据规则

Mock 数据必须集中放置：

```txt
frontend/src/mock/
```

按端和模块拆分：

```txt
mock/admin/training.ts
mock/admin/archive.ts
mock/admin/abilityProfile.ts
mock/admin/abilityList.ts
mock/admin/reports.ts
mock/mobile/todo.ts
mock/mobile/archive.ts
mock/mobile/activity.ts
mock/mobile/my.ts
```

禁止在页面组件中散落大量 mock 数组。
