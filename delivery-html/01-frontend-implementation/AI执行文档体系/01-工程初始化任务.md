## 1. 前端工程位置

```txt
frontend/
```

## 3. T1.1 创建 frontend Vue 工程

### 目标

在现有仓库中新建 `frontend/`，初始化 Vue 3 + Vite + TypeScript 最小可运行工程。

### 输出文件

```txt
frontend/package.json
frontend/index.html
frontend/vite.config.ts
frontend/tsconfig.json
frontend/src/main.ts
frontend/src/App.vue
frontend/src/env.d.ts
```

### 验收标准

```txt
1. frontend/ 目录存在
2. package.json 存在
3. index.html 存在
4. src/main.ts 存在
5. src/App.vue 存在
6. 可运行 npm run dev 或 pnpm dev
7. 不影响原有文档和效果图目录
```

### 注意

当前工具环境如果不能执行 `npm install` 或 `npm run build`，必须在结果中说明，不能宣称 build 已通过。

## 4. T1.2 接入 Tailwind CSS

### 目标

配置 Tailwind CSS 和全局样式入口。

### 输出文件

```txt
frontend/tailwind.config.ts
frontend/postcss.config.js
frontend/src/styles/main.css
frontend/src/styles/tokens.css
```

### 要求

```txt
1. main.css 必须在 main.ts 中引入
2. tokens.css 必须承载设计 token
3. Tailwind 配置必须覆盖 src 下的 Vue / TS 文件
4. 默认页面背景为浅色
```

### 验收标准

```txt
1. Tailwind 类名可正常生效
2. main.css 已在 main.ts 中引入
3. tokens.css 中定义基础颜色、圆角、阴影变量
4. 默认页面背景为浅色教育 SaaS 风格
```

## 5. T1.3 接入 shadcn-vue

### 目标

初始化 shadcn-vue，并生成首批 UI 基础组件。

### 首批组件

```txt
button
card
badge
input
select
table
tabs
dialog
sheet
dropdown-menu
tooltip
popover
separator
breadcrumb
```

### 输出文件

```txt
frontend/components.json
frontend/src/components/ui/
```

### 禁止

```txt
1. 禁止引入 Element Plus
2. 禁止引入 Ant Design Vue
3. 禁止引入 Naive UI
4. 禁止用其他组件库替代 shadcn-vue
```

### 验收标准

```txt
1. components.json 存在
2. ui 组件目录存在
3. Button、Card、Badge、Sheet 可正常引入
4. 未引入其他大型 UI 组件库
```
