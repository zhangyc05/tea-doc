# 教师综合发展平台｜Vue 前端落地 AI 执行文档入口

> 本文件是前端落地 AI 执行文档体系的入口索引。  
> 原长版手册已拆分为多个子文档，后续 AI 不应每次读取完整母版，而应先读总入口，再按任务类型读取对应子文档。

## 1. 为什么拆分

原完整手册内容较长，不适合后续 AI 每次任务都完整读取。

拆分后的目标是：

```txt
1. 降低 AI 每次任务读取负担
2. 避免关键信息被长文档淹没
3. 让不同任务只读取相关规范
4. 提高后续 AI 执行稳定性
5. 支持连续交接和任务追踪
```

## 2. 每次任务的读取方式

后续 AI 执行任务时，应按以下方式读取：

```txt
先读：AI执行文档体系/00-AI执行总入口.md
再按任务类型读取对应子文档
最后读取当前任务涉及的工程文件、效果图或页面规划
```

## 3. 文档体系目录

| 文档 | 用途 |
|---|---|
| `AI执行文档体系/00-AI执行总入口.md` | 每次任务必读，包含执行协议、禁止事项、任务索引和输出格式 |
| `AI执行文档体系/01-工程初始化任务.md` | Vue 工程初始化、Tailwind CSS、shadcn-vue 接入 |
| `AI执行文档体系/02-设计Token与视觉规范.md` | 视觉风格、设计 token、防止黑色后台跑偏 |
| `AI执行文档体系/03-组件规范.md` | 组件分层、通用组件 API、业务组件规则 |
| `AI执行文档体系/04-路由与页面台账.md` | 路由规则、页面映射、页面状态、mock 数据规则 |
| `AI执行文档体系/05-管理端页面任务.md` | 管理端 PC 页面还原任务，含资源库样板页拆分 |
| `AI执行文档体系/06-教师端页面任务.md` | 教师 PC 与教师手机端页面规则、文案边界 |
| `AI执行文档体系/07-AI任务执行记录与交接.md` | 直接提交 main、任务记录、失败处理、交接规范 |

## 6. 核心提醒

```txt
1. 每次只执行一个明确任务编号
2. 后续默认直接提交 main，不再新建分支和 PR
3. 不自行改变技术栈
4. 不自行新增无依据字段
5. 不把管理端做成黑色重后台
6. 不在教师端直接显示“候选数据”
7. 不把 AI 建议表达成正式结论
8. 不在 build 失败时宣称任务完成
9. 每次任务完成后更新任务记录
```
