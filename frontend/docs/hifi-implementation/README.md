# 前端高保真还原执行文档

本目录是后续前端页面还原的唯一执行入口。

后续 AI 执行前端任务时，只读取本目录下文档，不再从其他历史执行记录推断页面结构或组件结构。

## 阅读顺序

```txt
1. 先读 00-执行总入口.md
2. 再读 01-当前工程基础.md
3. 按任务类型读取对应文档：
   - 02-效果图识别规则.md
   - 03-组件提炼规则.md
   - 04-页面还原规则.md
   - 05-本地截图验收规则.md
   - 06-资源库页面重构任务清单.md
   - 07-页面路由与验收台账.md
```

## 核心原则

```txt
效果图识别 → 页面区域拆解 → 组件提炼 → Vue 实现 → 本地截图对比 → 修正验收
```

组件必须从目标效果图中提炼，不允许先凭经验设计通用组件后再拼页面。

页面完成标准不是“能运行”，而是“本地运行截图与目标效果图结构、密度、视觉层级基本一致”。
