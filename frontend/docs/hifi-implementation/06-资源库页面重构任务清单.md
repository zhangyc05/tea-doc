# 06｜资源库页面重构任务清单

## 1. 当前目标

资源库页面需要按目标效果图重新还原，作为管理端页面基准。

页面地址：

```txt
/admin/training/resources
```

## 2. 执行顺序

```txt
R1｜识别资源库效果图
R2｜提炼资源库页面组件
R3｜重构管理端壳子
R4｜重构资源库页面主体
R5｜本地截图对比
R6｜修正差异并验收
```

## 3. R1｜识别资源库效果图

输出：

```txt
1. 整体布局识别
2. 左侧导航识别
3. 顶部栏识别
4. 统计卡识别
5. 筛选区识别
6. 表格字段识别
7. 右侧概览栏识别
8. 分页识别
9. 视觉要点识别
```

完成标准：形成可执行的页面区域拆解，不写代码。

## 4. R2｜提炼资源库页面组件

输出组件清单：

```txt
AdminSidebar
AdminTopbar
MetricIconCard
ResourceFilterPanel
ResourceTable
ResourceOverviewPanel
ResourceDistributionList
PaginationBar
ResourceDetailSheet
FloatingAIAssistant
```

完成标准：每个组件明确 props、events、字段、视觉要点。

## 5. R3｜重构管理端壳子

改动范围：

```txt
src/components/layout/AdminSidebar.vue
src/components/layout/AdminTopbar.vue
src/layouts/AdminLayout.vue
src/styles/tokens.css
```

目标：左侧导航、顶部栏、页面内容宽度、背景和间距接近目标效果图。

## 6. R4｜重构资源库页面主体

改动范围：

```txt
src/pages/admin/training/ResourceLibraryPage.vue
src/mock/admin/training.ts
src/components/business/training/*
```

必须包含：

```txt
1. 顶部统计卡；
2. 左侧资源列表；
3. 两行筛选区；
4. 资源表格；
5. 右侧资源概览；
6. 分页；
7. 详情抽屉。
```

## 7. R5｜本地截图对比

执行：

```bash
cd frontend
npm run dev
```

打开：

```txt
http://localhost:5173/admin/training/resources
```

提交截图，与目标效果图逐项对比。

## 8. R6｜修正差异并验收

只有截图对比通过后，才可以进入后续页面。

## 9. 不得新增内容

资源库页面不得新增以下口径：

```txt
需求匹配结果
涉及计划统计
覆盖教师统计
推荐命中
评价结论
AI 正式结论
```

允许出现的资源本身统计：

```txt
资源数量
资源来源分布
培训级别分布
资源状态分布
资源完整度
更新时间
```
