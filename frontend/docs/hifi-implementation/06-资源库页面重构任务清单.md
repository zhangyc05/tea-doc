# 06｜资源库页面重构任务清单

## 1. 当前目标

资源库页面需要按目标效果图重新还原，作为管理端页面基准。

还原目标是响应式高保真：以目标效果图为桌面视觉基准，在不同桌面宽度下保持结构、比例、密度和层级一致，不把页面写死为某一个截图尺寸。

页面地址：

```txt
/admin/training/resources
```

## 2. 目标效果图

当前资源库目标效果图：

```txt
效果图/管理PC端/4发展活动/2培训管理/管理端PC｜培训管理｜资源库.png
```

目标图原始尺寸只用于识别比例、间距和视觉层级，不作为唯一验收视口。

## 3. 执行顺序

```txt
R0｜绑定目标效果图与响应式验收基准
R1｜识别资源库效果图
R2｜提取布局比例、断点规则与视觉 token
R3｜提炼资源库页面组件
R4｜重构管理端壳子
R5｜重构资源库页面主体
R6｜建立或执行固定截图流程
R7｜多视口本地截图对比
R8｜修正差异并验收
```

## 4. R0｜绑定目标效果图与响应式验收基准

输出：

```txt
1. 目标效果图路径；
2. 页面路由；
3. 必验桌面视口；
4. 响应式布局规则；
5. 不允许写死的尺寸范围；
6. 截图命名和差异记录方式。
```

必验桌面视口：

```txt
1280 × 800
1440 × 900
1536 × 864
1920 × 1080
```

完成标准：台账中目标效果图已绑定，验收口径不再写“待绑定”。

## 5. R1｜识别资源库效果图

输出：

```txt
1. 整体布局识别
2. 左侧导航识别
3. 顶部栏识别
4. 统计卡识别
5. 筛选区识别
6. 表格字段识别
7. 右侧概览栏识别
8. 分页识别
9. 视觉要点识别
10. 自适应时必须保持的结构关系
```

完成标准：形成可执行的页面区域拆解，不写代码。

## 6. R2｜提取布局比例、断点规则与视觉 token

输出：

```txt
1. 左侧导航宽度规则；
2. 顶部栏高度和右侧操作区规则；
3. 内容区最大宽度、边距和伸缩规则；
4. 四张统计卡的列数和换行规则；
5. 主表格与右侧概览栏比例；
6. 表格最小宽度和横向滚动规则；
7. 筛选区两行布局和换行规则；
8. 分页区域在窄桌面下的保持规则；
9. 主色、背景色、边框色、文字色、状态色；
10. 圆角、阴影、字号、字重、行高；
11. 表格行高、卡片内边距、模块间距、图标尺寸。
```

完成标准：明确哪些尺寸固定、哪些尺寸随屏幕伸缩、哪些区域在窄桌面下换行或滚动，并形成实现可用的视觉 token 清单。

## 10. R6｜建立或执行固定截图流程

执行：

```bash
cd frontend
npm run dev
```

打开：

```txt
http://localhost:5173/admin/training/resources
```

截图流程要求：

```txt
1. 优先使用 Playwright 或等价自动化方式；
2. deviceScaleFactor = 1；
3. 浏览器缩放 100%；
4. 截图产物保存到 frontend/docs/hifi-implementation/screenshots/resource-library/；
5. 文件名包含 resource-library、视口宽高、轮次或日期；
6. 如暂未建立脚本，人工截图也必须按同样视口和命名规则执行，并记录待补脚本事项。
```

基准视口：

```txt
1440 × 900
```

响应式视口：

```txt
1280 × 800
1536 × 864
1920 × 1080
```

## 11. R7｜多视口本地截图对比

按以下视口提交截图，与目标效果图逐项对比：

```txt
1440 × 900（基准视口，精细对齐）
1280 × 800（响应式稳定性）
1536 × 864（响应式稳定性）
1920 × 1080（响应式稳定性）
```

每个视口必须检查：

```txt
1. 左侧导航、顶部栏、主内容是否完整；
2. 统计卡是否按规则排列；
3. 筛选区是否保持两行结构或合理换行；
4. 表格列宽、行高、密度是否接近目标图；
5. 右侧资源概览是否完整显示或按规则下移；
6. 分页是否完整可见；
7. 是否存在文字重叠、控件溢出、表格压扁。
```

基准视口额外检查：

```txt
1. 左侧导航宽度和选中态；
2. 顶部栏高度、筛选控件尺寸；
3. 统计卡宽高、图标尺寸、数字字号；
4. 表格行高、列宽、边框；
5. 右侧概览卡片间距；
6. 分页高度和间距；
7. 颜色、圆角、阴影、字号、行高。
```

## 12. R8｜修正差异并验收

只有截图对比通过后，才可以进入后续页面。

差异记录必须包含：

```txt
视口尺寸
差异等级（P0/P1/P2）
差异位置
目标效果
当前效果
修正方式
是否已完成
关联截图文件
```

差异等级：

```txt
P0：结构缺失、模块错位、内容不可见、页面不可用；
P1：区域比例、视觉密度、表格列宽、右侧栏、分页、筛选区与目标明显不一致；
P2：颜色、阴影、圆角、图标、轻微间距、文案细节差异。
```

## 13. 不得新增内容

资源库页面不得新增以下口径：

```txt
需求匹配结果
涉及计划统计
覆盖教师统计
推荐命中
评价结论
AI 正式结论
```

允许出现的资源本身统计：

```txt
资源数量
资源来源分布
培训级别分布
资源状态分布
资源完整度
更新时间
```
