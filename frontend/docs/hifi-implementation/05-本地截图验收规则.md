# 05｜本地截图验收规则

## 1. 验收定位

页面验收以本地运行截图和目标效果图对比为准。

页面未完成截图对比前，不得标记为视觉验收通过。

## 2. 本地启动

```bash
cd frontend
npm install
npm run dev
```

页面地址以页面台账为准。

资源库页面当前地址：

```txt
http://localhost:5173/admin/training/resources
```

## 3. 截图要求

截图时应保持：

```txt
1. 浏览器缩放 100%；
2. 页面完整显示左侧导航、顶部栏、主内容；
3. 截图宽度接近目标效果图；
4. 不使用移动端模拟；
5. 不裁掉右侧栏或分页区。
```

## 4. 对比维度

每次截图对比必须检查：

```txt
1. 页面整体布局；
2. 左侧导航；
3. 顶部栏；
4. 面包屑和标题；
5. 统计卡；
6. 筛选区；
7. 主表格；
8. 右侧概览；
9. 分页；
10. 颜色、圆角、阴影、密度。
```

## 5. 验收状态

页面台账中的验收状态只能使用：

```txt
未开始
开发中
待本地截图
截图待修正
视觉验收通过
```

## 6. 差异记录

如果截图不一致，应记录差异清单：

```txt
差异位置
目标效果
当前效果
修正方式
是否已完成
```

## 7. 继续开发门槛

样板页未通过视觉验收前，不进入后续同类页面开发。

资源库页面是当前管理端样板页，必须先完成视觉验收，再进入需求管理、申请处理、记录总览等页面。
