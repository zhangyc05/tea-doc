## 5. 使用边界

当前代码可以作为工程基础，但页面视觉和组件结构必须以目标效果图重新校准。

后续页面开发时：

```txt
1. 可以复用已有工程目录和路由基础；
2. 可以复用基础 UI 组件；
3. 必须根据目标效果图重新判断组件是否需要升级或替换；
4. 页面结构不得仅依赖当前实现；
5. 页面完成后必须本地截图对比。
```
