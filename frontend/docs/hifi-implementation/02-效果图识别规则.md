# 02｜效果图识别规则

## 1. 识别目标

每个页面开发前，必须先识别目标效果图，而不是直接写 Vue。

识别结果必须回答：

```txt
1. 页面整体结构是什么？
2. 有哪些一级区域？
3. 每个区域内部有哪些模块？
4. 每个模块展示哪些字段？
5. 哪些内容是操作？哪些内容只是状态展示？
6. 哪些模块具有复用价值？
7. 哪些内容不能出现在页面中？
```

## 2. 必须识别的页面区域

```txt
1. 左侧导航
2. 顶部栏
3. 面包屑 / 页面路径
4. 页面标题区
5. 统计卡区域
6. 筛选区域
7. 主列表 / 主内容区域
8. 右侧辅助区域
9. 分页区域
10. 浮动 AI 助理
11. 抽屉 / 弹层 / 详情区域
```

如果目标效果图没有某个区域，应说明“未出现”，不要自行补充。

## 3. 字段识别要求

字段必须来自效果图或已确认业务规则。

字段识别需要写清：

```txt
字段名称
字段含义
字段所在模块
是否用于筛选
是否用于列表
是否用于详情
是否需要 mock
```

## 4. 操作识别要求

操作必须写清：

```txt
操作名称
触发位置
预期结果
是否当前页面必须实现
是否可以先做静态展示
```

未实现的操作不得做成可点击按钮。

## 5. 视觉识别要求

必须记录：

```txt
主色
背景色
卡片圆角
卡片阴影
表格密度
字号层级
左右栏比例
模块间距
选中态样式
状态标签样式
```

## 6. 响应式识别要求

目标效果图是桌面视觉基准，不是唯一固定视口。

识别效果图时必须补充判断：

```txt
1. 哪些区域应保持固定宽度；
2. 哪些区域应随屏幕伸缩；
3. 哪些模块在窄桌面下允许换行；
4. 哪些模块在窄桌面下应保持同一行；
5. 表格是否需要最小宽度和横向滚动；
6. 右侧辅助栏在宽度不足时是否下移；
7. 分页、按钮、筛选控件在窄桌面下如何保持可见。
```

## 7. 视觉 Token 提取要求

效果图识别必须输出可用于实现的视觉 token 线索：

```txt
主色
背景色
卡片背景色
边框色
主要文字色
次要文字色
按钮色
状态色
圆角
阴影
字号
字重
行高
表格行高
卡片内边距
模块间距
图标尺寸
```

## 8. 输出格式

每次识别效果图后，输出以下结构：

```txt
页面名称
目标截图
整体布局
区域拆解
字段清单
操作清单
组件候选
视觉要点
视觉 token
响应式保持关系
不可新增内容
待确认问题
```
