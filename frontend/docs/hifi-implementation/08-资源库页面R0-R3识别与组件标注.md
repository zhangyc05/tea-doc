# R1｜资源库效果图识别

## R1.1 整体布局

目标图是浅色蓝色系管理端页面：

```txt
管理端壳子
├─ 左侧固定导航
│  ├─ 品牌区：教师综合发展平台
│  ├─ 一级菜单：首页、能力清单、成长档案、教学反思、培训管理等
│  └─ 培训管理展开：计划管理、需求管理、资源库、申请处理、记录总览
├─ 顶部栏
│  ├─ 左侧路径：培训管理 / 资源库
│  └─ 右侧：全校下拉、2026 年度下拉、通知、头像、管理员
└─ 主内容区
   ├─ 4 张资源统计卡
   ├─ 主体两栏布局
   │  ├─ 左侧：两行筛选 + 新增资源按钮 + 资源表格 + 分页
```

# R2｜布局比例、断点规则与视觉 token

## R2.1 页面壳布局规则

| 区域 | 规则 | 估算值 |
|---|---|---|
| 左侧导航 | 固定宽度，不随内容区缩放 | `240–248px` |
| 顶部栏 | 固定高度 | `64–68px` |
| 主内容区 | 随视口伸缩，目标图宽桌面为全宽工作台 | 1440 下减去侧栏后自适应 |
| 主内容左右 padding | 桌面固定，中窄屏适当压缩 | `18–24px` |
| 页面背景 | 极浅蓝灰 | `#F7FAFF` / `#F8FAFE` |
| 内容卡片 | 白底、浅蓝灰边框、轻阴影 | 不使用深色后台风格 |

## R2.2 主体两栏规则

目标图主体为左侧大表格区 + 右侧资源概览栏。

```txt
左侧主区域：约 78%–80%
右侧概览栏：约 300px
两栏间距：16px
```

| 视口 | 主体布局 |
|---|---|
| 1280 × 800 | 优先保持可用性：右侧栏允许下移，表格保持最小宽度并横向滚动。 |
| 1440 × 900 | 基准视口：两栏并排，右栏约 300px，左侧表格占剩余宽度。 |
| 1536 × 864 | 两栏并排，表格列宽更舒展。 |
| 1920 × 1080 | 内容区可适度放宽，但不让表格和统计卡无限拉伸导致密度失真。 |

## R2.3 统计卡规则

目标图顶部 4 张统计卡一行，卡片内含圆形浅色图标底、标题、数字单位、说明。

```txt
卡片高度：136–144px
卡片间距：16px
卡片内边距：22–28px
图标底圆：72–80px
图标：30–36px
数字字号：28–32px
标题字号：14–15px
说明字号：13px
```

| 视口 | 规则 |
|---|---|
| ≥1440 | 4 卡一行。 |
| 1280 | 优先 4 卡一行；如文字拥挤允许 2×2，但需记录为响应式调整。 |
| 1920 | 4 卡一行，不无限拉宽，保持目标图密度。 |

## R2.4 筛选区规则

目标图筛选区位于表格卡片顶部，视觉上是白底卡片内部的两行工具区。

```txt
第一行：资源状态、培训方向、培训级别、资源来源
第二行：搜索框、重置、查询、右侧新增资源按钮
```

| 视口 | 规则 |
|---|---|
| 1280 | 筛选控件允许换行；查询、重置、新增资源必须可见。 |
| 1440 | 保持两行结构，新增资源在第二行右侧。 |
| 1536 / 1920 | 两行结构不变，不强行展开成单行。 |

## R2.5 表格规则

| 项 | 规则 |
|---|---|
| 表格最小宽度 | `980–1080px` |
| 横向滚动 | 1280 且右栏并排时必须允许；若右栏下移，可减少滚动压力。 |
| 行高 | `52–58px` |
| 表头高 | `42–46px` |
| 单元格 padding | 横向 `12–14px`，纵向 `10–12px` |
| 资源名称 | 可两行，保持主文本清晰。 |
| 级别 / 学时 | 同列两段文字，用 `/` 或换行组织。 |
| 操作列 | 保持最小宽度 `72–88px`，蓝色“查看”入口可见。 |
| 状态列 | 使用胶囊状态标签。 |

## R2.6 响应式断点规则

| 断点 | 页面策略 |
|---|---|
| `<1280` | 不作为必验桌面；保证基础可访问。 |
| `1280–1439` | 窄桌面：右侧概览可下移；表格可横向滚动；统计卡必要时 2×2。 |
| `1440–1535` | 基准桌面：两栏并排，4 张统计卡一行，筛选区两行。 |
| `1536–1919` | 稳定桌面：两栏并排，表格列宽更舒展。 |
| `≥1920` | 宽桌面：保持工作台密度，不让内容无限铺满。 |

# 4. 现有组件复用判断

| 当前组件 | 结论 | 原因 |
|---|---|---|
| `AdminLayout` | 可复用但需升级 | 当前壳子可用，但内容区宽度、顶部栏高度、两栏结构需按目标图校准。 |
| `AdminSidebar` | 可复用但需明显视觉校准 | 需要蓝色系品牌、图标、培训管理高亮、资源库浅蓝选中态。 |
| `AdminTopbar` | 需要升级 | 需补齐顶部路径、全校、2026 年度、通知红点、头像、管理员。 |
| `PageHeader` | 不建议用于本页主体 | 目标图没有内容区大标题说明，使用会增加无依据区域。 |
| `StatCard` | 建议升级为 `MetricIconCard` | 目标图需要大圆形图标底、数字单位和更高卡片。 |
| `FilterBar` | 不建议直接使用 | 当前结构不满足第一行 4 下拉、第二行搜索/按钮/新增资源。 |
| `Table` 基础组件 | 可作为底层 | 需要封装 `ResourceTable` 控制列、行高、滚动、分页。 |
| `TrainingResourceDetailSheet` | 可作为基础升级 | 字段需改为目标图资源字段，去掉无依据完整度/更新时间依赖。 |
| `StatusBadge` | 可复用但需校准 | 需支持可用、信息待完善、已停用的目标图胶囊样式。 |
| `FloatingAIAssistant` | 可复用 | 需检查不遮挡分页和右侧按钮。 |
