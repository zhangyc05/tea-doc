# R1｜资源库效果图识别

## R1.1 整体布局

资源库页面应为管理端浅色 SaaS 布局：

```txt
管理端壳子
├─ 左侧固定导航
├─ 顶部栏
└─ 主内容区
   ├─ 面包屑
   ├─ 页面标题区
   ├─ 顶部资源统计卡
   ├─ 主体两栏布局
   │  ├─ 左侧：筛选区 + 资源表格 + 分页
   │  └─ 右侧：资源概览 / 分布信息
   └─ 右下角浮动 AI 助理
```

页面重点不是培训需求、培训计划或教师覆盖情况，而是资源库本身的资源数量、类型、来源、状态、完整度和更新时间。

# R2｜布局比例、断点规则与视觉 token

## R2.1 页面壳布局规则

| 区域 | 规则 | 估算值 |
|---|---|---|
| 左侧导航 | 固定宽度，不随内容区缩放 | `224px` |
| 顶部栏 | 固定高度 | `56px` |
| 主内容区 | 随视口伸缩，最大宽度控制 | 当前 token 为 `1240px`，后续按目标图修正 |
| 主内容左右 padding | 桌面固定，中窄屏适当压缩 | `32px`，1280 可降到 `24px` |
| 页面背景 | 极浅灰绿 | `#F6F8F7` |

## R2.2 主体两栏规则

建议比例：

```txt
主内容主体区域 = 左侧主区域约 72% + 右侧概览栏约 28%
右侧栏宽度 = 280–320px
两栏间距 = 16–20px
```

| 视口 | 主体布局 |
|---|---|
| 1280 × 800 | 右侧概览栏允许下移；表格保持最小宽度并横向滚动。 |
| 1440 × 900 | 左侧主表格 + 右侧概览栏并排，是基准精细对齐视口。 |
| 1536 × 864 | 两栏并排，主表格稍增宽。 |
| 1920 × 1080 | 内容区不无限拉宽，可维持最大宽度或适当放宽到 1320–1440。 |

## R2.3 统计卡规则

```txt
卡片高度：88–104px
卡片间距：16px
卡片内边距：16–20px
图标：32–36px
数字字号：22–24px
标题字号：13–14px
说明字号：12px
```

| 视口 | 规则 |
|---|---|
| ≥1440 | 4 卡一行。 |
| 1280 | 优先 4 卡一行；如文字拥挤允许 2×2。 |
| 1920 | 4 卡一行，不应拉得过宽，可随内容最大宽度控制。 |

## R2.4 筛选区规则

目标任务要求两行筛选区，建议结构：

```txt
第一行：搜索框 + 主要筛选 + 重置
第二行：资源类型 / 状态 / 适用方向 / 提供方等筛选控件
```

| 视口 | 规则 |
|---|---|
| 1280 | 筛选控件允许换行，但搜索框和重置按钮保持可见。 |
| 1440 | 保持两行结构。 |
| 1536 / 1920 | 两行结构不变，不展开成一行导致层级弱化。 |

## R2.5 表格规则

| 项 | 规则 |
|---|---|
| 表格最小宽度 | `880–960px` |
| 横向滚动 | 1280 视口右栏并排时必须允许。 |
| 行高 | `56–64px` |
| 表头高 | `44–48px` |
| 单元格 padding | 横向 `12–16px`，纵向 `12px` |
| 文本溢出 | 资源名称可两行，编号为次级小字；其他列单行省略。 |
| 操作列 | 固定右侧或保持最小宽度 `88–104px`。 |
| 完整度列 | 最小宽度 `120px`。 |

## R2.6 响应式断点规则

| 断点 | 页面策略 |
|---|---|
| `<1280` | 不作为必验桌面；可保证基础可访问。 |
| `1280–1439` | 窄桌面：统计卡可 2×2；右侧概览可下移；表格横向滚动。 |
| `1440–1535` | 基准桌面：两栏并排，4 张统计卡一行。 |
| `1536–1919` | 稳定桌面：两栏并排，表格列宽更舒展。 |
| `≥1920` | 宽桌面：内容不无限铺满，保持最大宽度和视觉密度。 |

# 5. 需要确认的问题

1. 目标图二进制未展开像素内容：当前已绑定目标图路径和 SHA，但连接器没有返回可视化像素，R2 中 px token 为估算。进入 R6 / R7 时必须用本地截图重新量化和修正。
2. 右侧概览具体内容：建议仅保留资源来源分布、状态分布、信息完整度、最近更新时间。是否允许出现“培训级别分布”，需以目标图为准；文档允许该口径，但当前 mock 尚未定义培训级别。
3. 资源库是否需要“新增资源”按钮：当前文档没有明确要求，现阶段不纳入组件和操作，避免新增无依据操作。
4. 筛选字段是否只保留资源类型 + 状态：当前页面只有两个筛选；目标任务要求两行筛选区。建议第一阶段先标注搜索、资源类型、状态为必需，适用方向、提供方为候选，等目标图像素核对后决定是否进入实现。
5. 右侧概览在 1280 视口是否下移：从响应式稳定性看，建议 1280 下右栏下移，避免表格压扁；1440 以上保持两栏并排。
6. 资源编号是否作为表格次级信息保留：当前表格在资源名称下展示编号 `TR-001`；若目标图没有编号，应删除，不应为了信息量保留。
