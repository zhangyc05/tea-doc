# 00｜执行总入口

## 1. 执行定位

前端页面开发以已确认的高保真效果图为页面还原依据。

任何页面任务开始前，必须先完成效果图识别和组件提炼，再进入 Vue 实现。

## 2. 固定执行流程

```txt
1. 识别目标效果图
2. 拆解页面区域
3. 提炼页面组件
4. 确认数据字段和 mock 结构
5. 编写或调整 Vue 页面
6. 本地运行截图
7. 对比目标效果图
8. 修正差异
9. 更新页面台账
```

## 3. 禁止事项

```txt
1. 禁止先凭经验设计通用组件，再用组件拼页面。
2. 禁止只做到路由可访问或页面能运行就标记完成。
3. 禁止在没有效果图识别结论时新增页面字段。
4. 禁止为了填充页面增加无业务必要的模块。
5. 禁止把截图验收之前的页面标记为完成验收。
```

## 4. 页面完成标准

页面必须同时满足：

```txt
1. 页面结构与目标效果图一致；
2. 主要模块完整；
3. 信息层级清晰；
4. 视觉密度接近目标效果图；
5. 关键组件来自效果图提炼；
6. mock 数据集中管理；
7. 本地截图完成对比。
```
