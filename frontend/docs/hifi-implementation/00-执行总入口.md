# 00｜执行总入口

## 1. 执行定位

前端页面开发以已确认的高保真效果图为页面还原依据。

目标效果图是桌面视觉基准，不是唯一固定视口。页面需要做响应式高保真还原，在不同桌面宽度下保持结构、比例、密度和视觉层级稳定。

任何页面任务开始前，必须先完成效果图识别、布局比例与断点规则提取、组件提炼，再进入 Vue 实现。

## 2. 固定执行流程

```txt
1. 识别目标效果图
2. 拆解页面区域
3. 提取布局比例与响应式断点规则
4. 提炼页面组件
5. 确认数据字段和 mock 结构
6. 编写或调整 Vue 页面
7. 多视口本地运行截图
8. 对比目标效果图
9. 修正差异
10. 更新页面台账
```

## 3. 禁止事项

```txt
1. 禁止先凭经验设计通用组件，再用组件拼页面。
2. 禁止只做到路由可访问或页面能运行就标记完成。
3. 禁止在没有效果图识别结论时新增页面字段。
4. 禁止为了填充页面增加无业务必要的模块。
5. 禁止把截图验收之前的页面标记为完成验收。
6. 禁止把页面写死为单一截图尺寸。
7. 禁止只验收单一视口就标记响应式页面完成。
```

## 4. 页面完成标准

页面必须同时满足：

```txt
1. 页面结构与目标效果图一致；
2. 主要模块完整；
3. 信息层级清晰；
4. 视觉密度和布局比例接近目标效果图；
5. 关键组件来自效果图提炼；
6. mock 数据集中管理；
7. 多个桌面视口本地截图完成对比；
8. 不存在文字重叠、控件溢出、表格压扁、右侧栏裁切等响应式问题。
```

## 5. 当前优先任务

```txt
R0｜绑定资源库目标效果图与响应式验收基准
R1｜识别资源库效果图
R2｜提取布局比例与断点规则
R3｜提炼资源库页面组件
R4｜按效果图重构资源库页面
R5｜多视口截图对比与修正
R6｜固化资源库为管理端页面基准
```
