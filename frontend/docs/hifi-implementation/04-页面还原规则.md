# 04｜页面还原规则

## 1. 页面还原目标

页面还原的目标是让本地运行页面在结构、层级、密度和主要视觉语言上接近目标效果图，并在不同桌面宽度下保持稳定的响应式表现。

目标效果图是视觉基准，不是唯一固定视口。不得为了贴合某一张截图尺寸而把页面写死为固定宽高。

不能只以“页面能打开、数据能显示、按钮能点击”为完成标准。

## 2. 还原前置条件

开始写 Vue 前，必须已经完成：

```txt
1. 效果图识别结果
2. 页面区域拆解
3. 布局比例和响应式断点判断
4. 组件提炼清单
5. mock 字段清单
6. 多视口页面验收点
```

## 3. 页面结构还原要求

必须先还原大结构，再还原细节。

顺序固定为：

```txt
1. 页面壳：侧栏、顶部栏、内容区宽度
2. 页面主结构：上方统计、主内容、右侧辅助栏
3. 业务模块：筛选、列表、概览、分页
4. 响应式：主内容伸缩、右侧栏处理、表格最小宽度、统计卡换行
5. 细节：状态、图标、间距、圆角、阴影
6. 交互：筛选、详情、分页、按钮
```

## 4. mock 数据要求

mock 必须集中放在 `src/mock/` 下。

页面内不得散落大段 mock 数据。

mock 字段必须服务目标效果图，不为了填满页面新增无依据字段。

## 5. 操作实现要求

```txt
1. 已明确交互的操作可以实现。
2. 未明确交互的操作可以静态展示，但不能误导为已实现。
3. 无业务必要的操作不出现。
4. 页面主操作必须和效果图一致。
```

## 6. 视觉还原要求

每个页面必须检查：

```txt
1. 左侧导航是否与目标图一致；
2. 顶部栏是否与目标图一致；
3. 页面标题和面包屑层级是否一致；
4. 统计卡结构是否一致；
5. 筛选区行数和字段是否一致；
6. 表格字段和密度是否一致；
7. 右侧栏是否存在且结构一致；
8. 分页是否存在且结构一致；
9. 状态标签是否符合目标图；
10. 页面是否有明显空白或拥挤；
11. 多个桌面视口下是否无文字重叠、按钮溢出、表格压扁；
12. 页面缩放时是否保持目标图中的布局比例和视觉层级。
```

## 7. 响应式还原要求

桌面端页面优先保持目标图中的信息结构和比例关系。

必须明确以下规则：

```txt
1. 左侧导航宽度是否固定，是否允许收起；
2. 顶部栏高度和右侧操作区如何适配；
3. 内容区最大宽度、最小宽度、左右边距如何变化；
4. 统计卡在不同宽度下使用几列；
5. 主表格和右侧概览栏的比例关系；
6. 宽度不足时右侧栏是否下移，表格是否横向滚动；
7. 表格列的最小宽度和文本换行规则；
8. 筛选区控件如何换行，按钮是否保持可见；
9. 分页区在窄桌面下如何保持完整。
```

## 8. 提交前检查

提交前必须确认：

```txt
1. 是否更新页面台账；
2. 是否记录多视口本地截图验收状态；
3. 是否新增了无依据字段；
4. 是否存在未实现空按钮；
5. 是否影响其他已验收页面；
6. 是否存在仅适配单一截图尺寸的固定布局。
```
