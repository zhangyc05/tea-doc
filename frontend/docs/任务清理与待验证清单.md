# 任务清理与待验证清单

> 本文件用于集中管理 AI 前端落地过程中暂时未完成、待验证、待回收的事项。  
> 单个任务日志只记录当次执行结果；跨任务遗留事项统一沉淀在这里，避免后续遗漏。

## 1. 使用规则

```txt
1. 每次任务完成后，如产生跨任务未完成项，必须补充到本文件。
2. 如果某个待清理项已经完成，应移动到“已完成清理项”。
3. 不把未来正常排期任务全部堆进这里，只记录容易被遗漏的验证项、临时绕开项和技术债。
4. 不用本文件替代 ai-task-log.md；ai-task-log 记录任务历史，本文件记录待回收事项。
```
