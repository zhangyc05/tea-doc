# ability-list-base-assets

用于管理端「能力清单 / 基准模板」页面的资源文件。

## 文件清单

- `ability-list-base-hero-art.png`：基准模板页 Hero 条幅背景图
- `ability-list-base-hero-emblem.svg`：Hero 左侧主图标
- `icons/icon-ability-structure.svg`：能力结构图标
- `icons/icon-ability-basic.svg`：基本能力图标
- `icons/icon-ability-teaching.svg`：教学能力图标
- `icons/icon-ability-research.svg`：教研能力图标
- `icons/icon-ability-practice.svg`：实践能力图标
- `icons/icon-ability-service.svg`：服务能力图标

## 建议放置路径

```txt
frontend/src/assets/admin/ability-list/
```

## 建议引用

```ts
import baseHeroArt from '@/assets/admin/ability-list/ability-list-base-hero-art.png'
import baseHeroEmblem from '@/assets/admin/ability-list/ability-list-base-hero-emblem.svg'
import iconAbilityTeaching from '@/assets/admin/ability-list/icons/icon-ability-teaching.svg'
```
