# 管理端成长档案模块｜第二批页面实现任务

## 1. 任务目标

根据 `2成长档案.zip` 中剩余 3 张效果图，实现管理端 PC「成长档案 / 档案查询」链路。

本批先把内容和页面链路实现完整，后续再做细节视觉精修。

```txt
档案查询
→ 教师成长档案详情
→ 来源记录抽屉
```

文字模型不能识别图片，因此实现时必须以本文档为准，不得根据页面名称自由设计。

## 2. 本批对应效果图

```txt
管理端PC｜成长档案｜教师档案查阅.png
管理端PC｜成长档案｜阅读档案详情.png
管理端PC｜成长档案｜来源详情.png
```

第一批档案处理链路不在本批返修范围内，除非有路由冲突。

## 3. 当前仓库边界

当前侧边栏已有：

```txt
成长档案
- 档案处理
- 档案查询
```

本批不要修改左侧菜单结构，不要新增新的成长档案二级菜单。

当前已有路由：

```txt
/admin/archive/query
```

该路由目前是档案查询入口，需要替换为真实页面。

## 4. 需要新增页面文件

```txt
frontend/src/pages/admin/archive/ArchiveQueryPage.vue
frontend/src/pages/admin/archive/ArchiveTeacherDetailPage.vue
```

来源记录不要单独做页面，先作为 `ArchiveTeacherDetailPage.vue` 内的右侧抽屉实现。

## 5. 需要修改路由

修改：

```txt
frontend/src/router/admin.routes.ts
```

新增 lazy import：

```ts
const ArchiveQueryPage = () => import('@/pages/admin/archive/ArchiveQueryPage.vue')
const ArchiveTeacherDetailPage = () => import('@/pages/admin/archive/ArchiveTeacherDetailPage.vue')
```

路由映射：

```txt
/admin/archive/query              → ArchiveQueryPage.vue
/admin/archive/teacher/:teacherId → ArchiveTeacherDetailPage.vue
```

meta：

```ts
/admin/archive/query:
  title: '档案查询'
  module: '成长档案'
  layout: 'admin'
  menuKey: 'archive-query'

/admin/archive/teacher/:teacherId:
  title: '教师成长档案'
  module: '成长档案'
  layout: 'admin'
  menuKey: 'archive-query'
```

所有页面都必须包裹：

```vue
<AdminLayout active-key="archive-query">
  ...
</AdminLayout>
```
