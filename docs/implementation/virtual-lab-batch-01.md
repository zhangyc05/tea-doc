# 管理端虚拟教研室模块｜第一批粗实现任务

## 1. 任务目标

根据用户上传的 `4虚拟教研.zip` 中 4 张效果图，实现管理端 PC「虚拟教研室」模块第一批页面。

本批继续采用粗实现策略：先完成页面内容、路由和基础交互，后续再统一做视觉精修。

```txt
教研室管理
→ 教研室详情 / 教研活动管理
→ 教研活动详情
→ 教研记录 / 贡献记录详情
```

文字模型不能识别图片，因此实现时必须以本文档为准，不得根据页面名称自由设计。

## 3. 当前仓库边界

当前左侧菜单只有一个「虚拟教研室」入口：

```txt
虚拟教研室 → /admin/virtual-lab
```

本批不要新增左侧二级菜单，不要修改侧边栏结构。

当前已有路由：

```txt

```

该路由目前仍是占位页，需要替换为教研室管理页。

本批可新增详情路由，但不新增左侧菜单项。
