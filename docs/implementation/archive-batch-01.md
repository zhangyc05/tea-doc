# 管理端成长档案模块｜第一批页面实现任务

## 1. 任务目标

根据用户上传的 `2成长档案.zip` 效果图，实现管理端 PC「成长档案 / 档案处理」第一批页面。

第一批只做档案处理链路，不做档案查询链路。

```txt
档案处理工作台
→ 导入部门资料 / 上传资料
→ 导入批次详情 / 识别中
→ 导入批次详情 / 识别完成
```

本文件是给文字模型智能体执行的任务说明。不得根据页面名称自由设计，页面内容必须来自本文档。

## 7. 页面二：导入部门资料 / 上传资料

路径：

```txt
/admin/archive/import
```

页面标题：

```txt
导入部门资料
```

面包屑：

```txt
成长档案 / 档案处理 / 导入部门资料
```

说明：

```txt
上传部门掌握的教师相关资料，系统会先识别资料内容，涉及教师和建议归档维度，确认后再生成待处理记录，不会直接导入教师档案。
```

步骤条：

```txt
1 上传资料
2 系统识别
3 确认结果
4 生成待处理记录
```

当前步骤为第 1 步。

主体左右布局：

```txt
左侧：上传资料
右侧：上传说明
```

上传区文案：

```txt

可一次上传台账、名单、证书扫描件、项目材料、评审结果、通知文件等资料。
```

按钮：
