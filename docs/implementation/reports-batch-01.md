# 管理端分析报告模块｜第一批粗实现任务

## 1. 目标

根据用户上传的分析报告效果图，实现管理端 PC「分析报告」页面。

本批只做入口页粗实现：报告卡片、筛选、分类 Tab 和基础交互。后续再做详情页和视觉精修。

## 2. 当前仓库边界

当前左侧菜单已有：

```txt
分析报告 → /admin/reports
```

不要新增二级菜单，不要修改侧边栏结构。

当前 `/admin/reports` 是占位页，需要替换为真实页面。


## 5. 页面结构

页面标题：

```txt
分析报告
```

说明文案：

```txt
基于当前平台数据，用 AI 生成分析报告、分析大屏或专题解读。
```

分类 Tab：

```txt
全部
分析报告
分析大屏
专题解读
数据问答
```

默认选中「全部」。

筛选区：

```txt
对象：全部
周期：2026 年度
状态：全部
搜索框：搜索报告名称 / 分析问题
```

报告卡片布局：3 列 2 行。
