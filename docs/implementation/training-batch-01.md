# 管理端培训管理模块｜第一批粗实现任务

## 1. 目标

根据 `2培训管理.zip` 的 8 张效果图，先完成培训管理模块的页面内容、路由和基础交互，后续再统一做视觉精修。

本批范围：

```txt
计划管理 → 新建培训计划抽屉 → 计划详情
资源库
需求管理
申请处理
记录总览 → 记录详情
```

文字模型不能识别图片，请严格按本文档实现，不要自由设计。

## 2. 侧边栏调整

当前培训管理下缺少「计划管理」。请在 `frontend/src/components/layout/AdminSidebar.vue` 的 training children 中补充：

```ts
{ key: 'training-plans', label: '计划管理', to: '/admin/training/plans' }
```

建议顺序：

```txt
计划管理
需求管理
资源库
申请处理
记录总览
```

不要改其他模块菜单。

## 4. 路由修改

修改 `frontend/src/router/admin.routes.ts`。

路由映射：

```txt
/admin/training/plans                 → TrainingPlanPage.vue
/admin/training/plans/:planId         → TrainingPlanDetailPage.vue
/admin/training/resources             → TrainingResourcePage.vue
/admin/training/demands               → TrainingDemandPage.vue
/admin/training/applications          → TrainingApplicationPage.vue
/admin/training/records               → TrainingRecordPage.vue
/admin/training/records/:recordId     → TrainingRecordDetailPage.vue
```

各页面使用对应 menuKey：

```txt
training-plans
training-resources
training-demands
training-applications
training-records
```

所有页面必须包裹 `AdminLayout`。

## 5. 通用要求

```txt
使用 AdminLayout。
保持蓝白教育治理 SaaS 风格。
优先复用 admin-card、admin-table、badge-status、btn-primary、btn-secondary、btn-link。
全部使用页面内 mock 数据。
不接后端。
本批只做粗实现，不做视觉精修。
```
